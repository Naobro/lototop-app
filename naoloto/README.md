# NAO LOTO

ロト7・ロト6・ミニロト・ナンバーズ3・ナンバーズ4の過去当選番号を蓄積し、
出現回数・出現率・出現間隔などを分析するサイト。npm等のビルド環境は使わず、
HTML/CSS/JavaScriptのみで構成している。

## ディレクトリ構成

```
NAOLOTO/
├── index.html                # サイトTOP
├── css/
│   ├── common.css            # 全体共通デザイン
│   └── analysis.css          # 分析ページ専用スタイル
├── js/
│   └── analysis/
│       ├── stats.js          # 集計ロジック（ロト系共通）
│       ├── render.js         # HTML描画処理（ロト系共通）
│       └── loto7.js          # ロト7ページの設定・初期化
├── data/
│   └── loto7.json            # ロト7 過去当選番号データ
├── pages/
│   └── loto7/
│       └── index.html        # ロト7 無料分析ページ
└── images/                   # 画像置き場（現状未使用）
```

ロト6・ミニロト・ナンバーズ3・ナンバーズ4を追加するときは、
`data/<種別>.json` と `pages/<種別>/index.html`、`js/analysis/<種別>.js` を
ロト7と同じ形で増やしていけばよい（`stats.js` / `render.js` はロト系なら
そのまま使い回せる想定）。

## data/loto7.json の形式

当選1回分を1つのオブジェクトとして配列に追加する。

```json
{
  "回号": 693,
  "日付": "2026-09-04",
  "本数字": [1, 2, 3, 4, 5, 6, 7],
  "ボーナス数字": [8, 9]
}
```

- `回号`：ロト7の開催回（半角数字）
- `日付`：抽せん日（`YYYY-MM-DD`形式）
- `本数字`：本数字7個の配列（順不同でよい。ページ側で自動的に並び替えて表示する）
- `ボーナス数字`：ボーナス数字2個の配列

### 新しい回を追加する手順

1. `data/loto7.json` を開く。
2. 配列の**最後の `}` の直後にカンマ `,` を追加**し、改行して新しいオブジェクトを追加する。
3. 最後に追加した要素の後にはカンマを付けない（JSONの文法エラーになる）。
4. 保存してブラウザをリロードすれば、分析ページに自動で反映される
   （回号の順序はページ側で自動的に並び替えるため、末尾以外に追加しても問題ない）。

追加例（末尾の要素にカンマを足してから新しい要素を足す）：

```json
  {
    "回号": 692,
    "日付": "2026-08-28",
    "本数字": [7, 9, 15, 18, 20, 28, 31],
    "ボーナス数字": [21, 34]
  },
  {
    "回号": 693,
    "日付": "2026-09-04",
    "本数字": [1, 2, 3, 4, 5, 6, 7],
    "ボーナス数字": [8, 9]
  }
]
```

JSONの文法ミス（カンマの付け忘れ・付けすぎ）があると分析ページが真っ白になるので、
保存前に https://jsonlint.com などで構文チェックすると安全。

## ローカルで確認する方法

分析ページは `fetch()` で `data/loto7.json` を読み込む仕組みのため、
**HTMLファイルをダブルクリックして直接ブラウザで開くと、
セキュリティ制限（CORS）によりデータが読み込めない**。
必ず簡易サーバーを立てて確認すること。

```bash
cd NAOLOTO
python3 -m http.server 8000
```

その後ブラウザで `http://localhost:8000/` を開く。
（本番のColorfulBoxなど、http/httpsで配信される環境ではこの制限は発生しない）

## 現在のデータについて

`data/loto7.json` の初期データは、既存の集計元
`https://raw.githubusercontent.com/Naobro/lototop-app/main/data/loto7_50.csv`
（第603回〜第692回、2024-11-29〜2026-08-28）を新形式に変換して投入したもの。
以降はこのファイルに手動で新しい回を追記していく。
